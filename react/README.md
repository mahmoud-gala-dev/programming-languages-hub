# ⚛️ منصة وموسوعة خريطة طريق React.js الشاملة (من المبتدئ إلى الاحتراف)

> منصة تعليمية تفاعلية متكاملة مبنية بـ **React + Vite + Tailwind CSS** تم إنشاؤها لتعليم وتدريب المتعلمين على مسار React.js من الصفر المطلق وفق منهجية علمية مبسطة تعتمد على الأمثلة الحياتية، الكود المشروح سطر بسطر، بطاقات الإنفوجرافيك، والتمارين التطبيقية.

---

## 🌟 مميزات المنصة الرئيسية

1. **القسم الأول كاملاً: أساسيات تطوير الويب (35 درساً تفصيلياً)**:
   - **الموضوع 1:** مقدمة في تطوير الويب (7 دروس: مفهوم Frontend، الفرق بين Frontend و Backend، المتصفح والخادم، HTTP و HTTPS، CSR، SPA، وأدوات DevTools).
   - **الموضوع 2:** أساسيات HTML (8 دروس: هيكل الصفحة، العناصر والخصائص، العناوين والفقرات، الصور والجداول، النماذج، العناصر الدلالية، إمكانية الوصول a11y، وفحص النماذج).
   - **الموضوع 3:** أساسيات CSS (12 درساً: طرق الكتابة، أوزان المحددات، الألوان والخطوط، نموذج الصندوق Box Model، خاصية Display، التموضع Position، نظام Flexbox، نظام CSS Grid، التجاوب بـ Media Queries، متغيرات CSS، الحركات والانتقالات، والأصناف الزائفة).
   - **الموضوع 4:** أدوات تطوير الويب (8 دروس: VS Code، سطر الأوامر CLI، تثبيت Node.js، مدير الحزم npm، ملف package.json، فحص المتصفح المتقدم، تنسيق Prettier، وحراسة ESLint).

2. **النقاط الـ 10 الإلزامية لكل درس**:
   - تعريف مبسط باللغة العربية الفصحى.
   - تشبيه واقعي من الحياة اليومية.
   - لماذا نحتاجه والمشكلة التي يحلها.
   - جدول المصطلحات الإنجليزية مع النطق والترجمة.
   - الصيغة البرمجية العامة (Syntax).
   - مثال عملي بسيط مع **تعليق عربي فوق كل سطر كود**.
   - مثال عملي متقدم وتطبيقي.
   - محاكي تشغيل مباشر (Live Code Preview) داخل المتصفح.
   - شرح المخرجات.
   - أخطاء شائعة (Common Mistakes) مع الصواب وسبب الخطأ.
   - نصائح المحترفين (Best Practices).
   - بطاقة إنفوجرافيك مرئية مع زر تحميل فوري كصورة PNG عالية الدقة.

3. **اختبارات الفهم والتمارين التطبيقية**:
   - 3 أسئلة تفاعلية مع تصحيح فوري وشرح تعليمي واحتفال كونفيتي بعد كل موضوع رئيسي.
   - تمرين عملي مع تلميحات قابلة للطي وحل نموذجي كامل.

4. **ملخصات ومشاريع الختام**:
   - ملخص شامل بالنقاط الثماني الذهبية.
   - جدول المرجع السريع (Cheat Sheet) لأهم 20 أمراً وصيغة برمجية قابل للبحث والنسخ.
   - مشروع تطبيقي متكامل (موقع شركة تقنية متجاوب) مع إمكانية تجربة الموقع حياً أو تنزيل ملف `index.html`.
   - إنفوجرافيك القسم الشامل فائق الدقة.

5. **كتاب الـ PDF الإلكتروني**:
   - نافذة متكاملة لعرض وتحميل كتاب الـ PDF لكافة دروس وإنفوجرافيكس القسم الأول.
   - دعم مباشر للطباعة النقطية والمتجهية (Vector PDF Print).

6. **المعلم الذكي المدمج (Gemini AI Tutor)**:
   - نافذة محادثة تفاعلية تجيب على تساؤلات المتعلم مدعومة بنموذج Google Gemini، ومزودة برقاقات سريعة لاختبار الفهم وتوليد تشبيهات إضافية.

## 🚀 كيفية تشغيل المشروع

افتح سطر الأوامر (Terminal أو PowerShell) في مجلد المشروع ونفذ:

\`\`\`bash
# 1. الدخول إلى مجلد المشروع
cd e:\\KD\\lang\\react

# 2. تشغيل خادم التطوير السريع
npm run dev
\`\`\`

ثم افتح الرابط في متصفحك:
👉 \`http://localhost:5173/\`

---

## 🛠️ بناء نسخة الإنتاج (Production Build)

\`\`\`bash
npm run build
\`\`\`
يتم توليد ملفات الإنتاج المجهزة للنشر في مجلد \`dist/\`.
