# 🚀 منصة خريطة طريق ASP.NET Core MVC الشاملة (من الصفر إلى الاحتراف)

منصة تعليمية بصرية وتفاعلية متكاملة مبنية باستخدام **React 19 / Vite** و **Tailwind CSS v4**، تم تصميمها خصيصاً لتغطية مسار احتراف وتطوير تطبيقات الويب باستخدام **ASP.NET Core MVC** من الأساسيات الصفرية وحتى المعمارية المتقدمة للشركات الكبرى.

---

## 🌟 المميزات الرئيسية للمنصة:

1. **الخريطة الكاملة (33 قسماً • 206 موضوعاً • 1803 درساً تفاعلياً)**:
   - تغطية شاملة ودقيقة لكافة أقسام لغة C#، .NET 8/9/10، Entity Framework Core، SQL Server، الأمان والهوية، المعمارية النظيفة، Docker، والـ DevOps.
2. **المنهج البيداغوجي الموجه للمبتدئين تماماً**:
   - شرح كل مفهوم من خلال: تعريف مبسط، تشبيه واقعي من الحياة اليومية، لماذا نحتاجه، قاموس المصطلحات الإنجليزية وترجمتها ونطقها، الصيغة العامة Syntax، كود عملي بسيط مع تعليق عربي فوق كل سطر، كود متقدم للشركات، شرح المخرجات، أخطاء شائعة مع الصواب والسبب الهندسي، وأفضل الممارسات.
3. **استوديو الإنفوجرافيك التفاعلي القابل للتحميل كصورة (PNG / SVG)**:
   - بطاقة إنفوجرافيك بصرية مخصصة لكل درس من الـ 1803 درساً توضح الخطوات والمعمارية مع إمكانية التحميل الفوري بنقرة زر بجودة عالية.
4. **استوديو الكتاب الإلكتروني الشامل وتصدير الـ PDF**:
   - قارئ رقمي يجمع دروس القسم أو المنهاج كاملاً ككتاب أنيق مع الرسوم والجداول، مع إمكانية تصدير وتحميل كتاب PDF كامل أو الطباعة المتجهية المباشرة.
5. **مجمع مفاتيح Gemini AI والمدرب الذكي التفاعلي**:
   - مدمج مسبقاً بالمفتاح الخاص بك مع فحص متوازي وتدوير تلقائي عند انتهاء الحصة اليومية (429 Rate Limit Failover).
   - معلم ذكي يجيب على أسئلة المتعلم ويشرح الأكواد ويختبر الفهم لحظياً.
6. **أدوات المذاكرة والتفاعل المتقدمة**:
   - نظام التظليل النيون الذكي بأربعة ألوان وحفظ الملاحظات في LocalStorage.
   - اختبارات سريعة "اختبر فهمك" (3 أسئلة مع الإجابة والشرح).
   - تمارين برمجية عملية مع التلميحات والحلول المشروحة واحتفالات Confetti.
   - ملخص شامل، جدول مرجعي سريع للأوامر (Cheat Sheet)، ومشروع تطبيقي صغير لكل قسم.

---

## 🛠️ كيفية تشغيل المنصة محلياً:

```bash
# الانتقال إلى مجلد المشروع
cd ASP.NET

# تشغيل خادم التطوير السريع
npm run dev

# أو لبناء نسخة الإنتاج
npm run build
```
