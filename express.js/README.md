# 🚀 منصة خريطة طريق Express.js الشاملة (من الصفر إلى الاحتراف)

منصة تعليمية تفاعلية متكاملة وشاملة مبنية بأحدث تقنيات الويب (**React 19**, **Vite**, **Tailwind CSS v4**)، مصممة لتدريس إطار العمل الشهير **Express.js** وفق المعايير العالمية للبنية التحتية الخلفية (Backend Architecture).

---

## 🌟 الميزات والمواصفات الرئيسية

1. **المنهج الشامل (27 قسماً، 154 موضوعاً رئيسياً، 1315 درساً تفصيلياً)**:
   - يغطي كل شيء بدءاً من أساسيات بروتوكول HTTP والشبكات، وصولاً إلى بناء الـ Microservices وتأمين الخوادم والـ DevOps.
   - محتوى مكتوب باللغة العربية بأسلوب تعليمي مبسط مع مراعاة المبتدئين تماماً.

2. **الأركان التعليمية القياسية لكل درس (10+ ركائز)**:
   - **التعريف المبسط**: ما هو المفهوم بلغة واضحة ومباشرة.
   - **تشبيه من واقع الحياة اليومية (Everyday Analogy)**: لترسيخ الفكرة ذهنياً.
   - **لماذا نحتاجه؟**: المشكلة التي يحلها والهدف المعماري منه.
   - **قاموس المصطلحات البرمجية (Vocabulary Table)**: الاسم بالإنجليزي، النطق العربي الصوتي، والمعنى التقني الدقيق.
   - **الصيغة البرمجية العامة (Syntax Structure)**.
   - **مثال عملي مبسط**: يحتوي على **تعليق عربي فوق كل سطر كود**.
   - **تطبيق عملي متقدم (Real-World)**: شفرة برمجية احترافية قابلة للاستخدام الفعلي في بيئات الإنتاج.
   - **محاكي تشغيل الكود (Live Code Simulator)**: بيئة تجريبية لاختبار الكود ومحاكاة مخرجات الخادم.
   - **شرح المخرجات وتفسير سلوك الخادم بالتفصيل**.
   - **أخطاء برمجية شائعة (Common Mistakes)**: مع الخطأ، الصواب، والسبب الهندسي.
   - **نصائح المحترفين وأفضل الممارسات (Best Practices)**.
   - **اختبر فهمك (Interactive Quiz)**: أسئلة تفاعلية مع تصحيح فوري وشرح توضيحي.
   - **تمرين تطبيقي عملي (Exercise & Solution)**: مع تلميحات وحل تفصيلي مشروح سطراً بسطر.
   - **بطاقة إنفوجرافيك ملخصة للدرس**: تصميم بصري فائق الجاذبية يدعم التحميل المباشر كصورة **PNG عالية الدقة**.

3. **خواتيم الأقسام المتقدمة**:
   - **خلاصة وقواعد الذهب (Golden Rules)**: أبرز القواعد البرمجية للقسم.
   - **الجدول المرجعي السريع (Cheat Sheet)**: شفرات وأوامر سريعة مع إمكانية النسخ الفوري.
   - **المشاريع التطبيقية (Capstone Projects)**: مشاريع حقيقية مع هيكل الملفات وكود عملي كامل.
   - **خريطة القسم الذهنية (Section Infographic Map)**: إنفوجرافيك شامل لكامل موضوعات القسم قابل للتنزيل كصورة PNG.

4. **كتاب إلكتروني شامل (Complete eBook PDF & Vector Print)**:
   - عارض مخصص للكتاب مع غلاف احترافي، فهرس موضوعات، وشروحات كاملة، مع إمكانية التصدير كملف **PDF متعدد الصفحات** والطباعة المتجهية المباشرة.

5. **المعلم الذكي المدمج (Google Gemini AI Tutor)**:
   - متصل مباشرة بنموذج `gemini-flash-latest` للإجابة الفورية وتصحيح الأكواد وتقديم أمثلة إضافية.
   - يتضمن نافذة إدارة مجمع المفاتيح (Key Pool Manager) لاختبار سرعة الاستجابة وإضافة مفاتيح بديلة.

## 🛠️ كيفية تشغيل المشروع محلياً

```bash
# الانتقال إلى مجلد المشروع
cd e:\KD\lang\express.js

# تثبيت الحزم (إن لم تكن مثبتة)
npm install

# تشغيل خادم التطوير السريع
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
