# 🟢 منصة وموسوعة خريطة طريق Node.js الشاملة (من الصفر إلى الاحتراف)

> منصة تعليمية تفاعلية متكاملة مبنية بـ **React 19 + Vite + Tailwind CSS (Material Design 3)** تم إنشاؤها لتعليم وتدريب مطوري الـ Backend على مسار **Node.js** بالكامل من الصفر المطلق وحتى الأنظمة الموزعة وهندسة الإنتاج، وفق منهجية علمية مبسطة تعتمد على الأمثلة الحياتية، الكود المشروح سطراً بسطر، بطاقات الإنفوجرافيك، والتمارين التطبيقية.

---

## 🌟 مميزات المنصة الرئيسية

1. **المنهج الكامل (23 قسماً و 127 موضوعاً رئيسياً و 950+ درساً تفصيلياً)**:
   - **القسم 1:** أساسيات البرمجة وتطوير الويب
   - **القسم 2:** التعرف على Node.js وإعداد بيئة العمل
   - **القسم 3:** أساسيات JavaScript اللازمة لتعلم Node.js
   - **القسم 4:** JavaScript غير المتزامنة وEvent Loop
   - **القسم 5:** إدارة المشاريع والحزم والوحدات (npm & Modules)
   - **القسم 6:** الوحدات الأساسية في Node.js (Core Modules)
   - **القسم 7:** بناء خوادم HTTP باستخدام Node.js
   - **القسم 8:** احتراف Express.js وبناء REST APIs
   - **القسم 9:** استخدام TypeScript مع Node.js
   - **القسم 10:** قواعد البيانات العلائقية SQL (PostgreSQL & Prisma)
   - **القسم 11:** قواعد بيانات NoSQL والتخزين المؤقت (MongoDB & Redis)
   - **القسم 12:** المصادقة والتفويض وأمان التطبيقات (JWT, OAuth, OWASP)
   - **القسم 13:** رفع الملفات والتعامل مع Streams وObject Storage
   - **القسم 14:** هندسة تطبيقات Backend (Clean Architecture & SOLID)
   - **القسم 15:** الاختبارات وتصحيح الأخطاء وجودة الكود (node:test, Supertest)
   - **القسم 16:** تطبيقات الوقت الحقيقي والمهام الخلفية (WebSockets & BullMQ)
   - **القسم 17:** تحسين الأداء والتوسع (Worker Threads, Cluster, Scaling)
   - **القسم 18:** التكامل مع الخدمات الخارجية والذكاء الاصطناعي (Webhooks, AI APIs)
   - **القسم 19:** Docker والنشر وDevOps (Compose, VPS, Nginx, CI/CD)
   - **القسم 20:** مراقبة تطبيقات الإنتاج والموثوقية (Pino, Prometheus, Grafana)
   - **القسم 21:** الموضوعات المتقدمة في Node.js (Internals, TCP/UDP, Diagnostics)
   - **القسم 22:** المشروعات التطبيقية من المبتدئ إلى المحترف (8 مشروعات حقيقية)
   - **القسم 23:** الاستعداد لسوق العمل والاحتراف والمقابلات التقنية

2. **النقاط الإلزامية لكل درس (The 10 Pedagogical Pillars)**:
   - تعريف مبسط باللغة العربية الفصحى.
   - تشبيه واقعي من الحياة اليومية (Everyday Analogy).
   - لماذا نحتاجه والمشكلة التي يحلها (Why & Problem Solved).
   - جدول المصطلحات الإنجليزية مع النطق المعرب والترجمة.
   - الصيغة البرمجية العامة (Syntax).
   - مثال عملي بسيط مع **تعليق عربي فوق كل سطر كود**.
   - مثال عملي متقدم وتطبيقي (Real-world Implementation).
   - محاكي تشغيل مباشر (Live Code Preview) مع محاكاة الطرفية.
   - تفسير نواتج التشغيل وسلوك الخادم.
   - أخطاء شائعة (Common Mistakes) مع الصواب وسبب الخطأ.
   - نصائح المحترفين (Best Practices).
   - بطاقة إنفوجرافيك مرئية مع زر تحميل فوري كصورة PNG عالية الدقة.
   - سؤال اختبار سريع وتمرين برمجي مع حل نموذجي وتلميحات.

3. **بطاقات الإنفوجرافيك وتنزيل الصور (PNG Export)**:
   - بطاقة إنفوجرافيك مرجعية لكل درس تلخص مراحله وقواعده.
   - زر تنزيل مباشر كصورة PNG فائقة الجودة بدقة 2x مع معالجة وتطهير فضاءات ألوان المتصفح الحديثة.

4. **كتاب الـ PDF الإلكتروني الشامل (Complete PDF Book)**:
   - نافذة متكاملة لعرض وتحميل كتاب الـ PDF لكافة دروس وإنفوجرافيكس القسم.
   - دعم مباشر للطباعة المتجهية فائقة النقاء (Vector Print).

5. **المعلم الذكي المدمج (Gemini AI Tutor)**:
   - نافذة محادثة تفاعلية تجيب على تساؤلات المتعلم مدعومة بنموذج Google Gemini 1.5 Flash.
   - مجمع مفاتيح (Key Pool) مع تبديل تلقائي عند انتهاء الحصة وفحص سرعة الاستجابة بالتوازي.

## 🚀 كيفية تشغيل المشروع

افتح سطر الأوامر (Terminal أو PowerShell) في مجلد المشروع ونفذ:

\`\`\`bash
# 1. الدخول إلى مجلد المشروع
cd e:\KD\lang\nodejs

# 2. تشغيل خادم التطوير السريع
npm run dev
\`\`\`

ثم افتح الرابط في متصفحك:
👉 \`http://localhost:5173/\`

## 🛠️ بناء نسخة الإنتاج (Production Build)

\`\`\`bash
npm run build
\`\`\`
يتم توليد ملفات الإنتاج المجهزة للنشر في مجلد \`dist/\`.
